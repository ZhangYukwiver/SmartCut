# 可选解析模型的复刻流程

剪辑模型必需，解析模型可选。两者至少一个必须能理解图片。没有解析模型时，剪辑模型同时分析画面和执行剪辑；不能看图的纯文本模型无法独立完成复刻。

原片 → 本地读取时间戳、帧、镜头和节拍 → 视觉模型输出分层参数 → 校验 → 实际渲染 → 全部源帧比较 → 最多两轮视觉修正 → 独立图层和原声音轨。

初次复刻、AI 剪辑中的参考解析和后续校准共用 `server/aiEdit/vision.mjs`。解析模型优先。普通画面分析中，视频明确不支持、格式被拒或请求过大时，同一模型可改用图片；鉴权、额度或其他服务故障进入备用模型判断。运动复核必须发送实际短视频，不降级成截图或本地纯文本 CLI；无可用视频模型时明确运动未验证。一轮任务中不再返回已经失败的服务，取消后不再发请求。

自动输入默认为图片，视频能力和图片能力分别记录，网络故障不改变能力判断。支持视频画面不代表能够理解音轨。原声由本地单独提取，不依赖模型转写。

内部实验可在工具上下文指定 `visualInput: 'images' | 'video'`，不写用户配置。指定视频仍尊重已知的 `videoInput: false`；绘制图层校准使用连续帧对照，网页运动校准使用下面的短视频流程。参数补正、格式降级和备用调用均保留实际输入记录，不能把混合路线当作纯视频成功。

`vision.calls` 记录角色、运行时、实际模型、图片或视频输入、HTTP 尝试、状态、耗时，以及服务返回的用量。没有返回的用量保持缺失，不填零。会话消息保存 `visionCalls`；操作步骤展示模型、输入方式与切换原因。凭据和模型内部推理不进入记录。

网页动画的「自动校准」复用同一工程，由主剪辑模型修改、视频模型复核、本地渲染器生成确定的画面：

1. 读取当前时间线、页面和已有候选，根据连续画面及用户纠正先判断合成结构，分别追踪遮挡边界与内部纹理。区分底层连续播放加上层遮罩揭开、贴图运动和独立素材入场；不把一种特效假设套到所有参考。已有有效判断优先复用，缺少干净底片时明确素材缺口。
2. 做最小局部修改，`preview_page` 检查构图和加载异常；透明页面保留 Alpha 通道检查重画一致性，不将铺黑底后的静帧送模型付费评审。`review_video_clip` 渲染问题前后的 2–4 秒（支持 0.5–12 秒，5 或 10 fps）。时间线上的网页候选连同底层和其他轨道完整合成，使用与正式导出相同的合成器。`start` 仍为页面秒数，按片段截取自动换算成时间线时钟；同页用于多处时需指定 `clip_id`。参考仍按保存的页面时间偏移和裁切对齐。区间含合成器不支持的效果时明确拒绝，不能省略效果后判通过。
3. 只有视频评审明确改善、给出依据且无回退时，自动校准才允许 `write_page(preview_id)` 采纳同一候选；保存前重核合成及素材指纹，防止沿用单层或过期评审。无法读视频、回答格式无效或结论不确定均不算通过。评审只覆盖输入区间，不证明音轨、出生瞬间或全片逐帧一致。
4. 每轮最多 4 次视频复核，连续两份不同内容无改善时停止，同一内容换候选编号不算新版本。相同材料和问题复用结论，没有新证据不盲调；不确定时只补能区分结构假设的短区间。采纳前复查原来正常的关键时刻与转场；确认最终版本后按用户要求导出全片，不在每轮重复全片编码。

每个会话最近 6 份候选跨轮和重启保留，正式页仍是时间线的事实源。短片缓存由页面、区间内的合成结构和素材依赖、区间、裁切及采样率决定；评审还绑定问题和模型配置。复用结果不再请求模型。候选仅替换临时合成文件中的页面引用，不改正式页面或时间线。删除会话同时清理候选与对照短片。

对话显示本轮及累计视觉用量。已知北京区 Qwen3.8-Max 按调用时记录的公开原价估算；未知价格或缺失用量明确列出，不当作零费用。估算不是账单实扣，不含优惠、主剪辑模型、生成素材和本地渲染。缓存命中不新增调用记录。

复刻操作的 `verification` 随会话步骤保存首版和最终版的全片、局部、帧间及最差帧指标，以及每个候选的采纳结果和退化诊断。原生工程保存独立绘制参数，MP4 用同一套绘制器实际导出；画面工程 ZIP 重新导入不等于恢复原生图层参数编辑。

图片预处理覆盖整段时间线，并在画面变化密集区域加入邻接帧和局部放大。校准按实际源帧时间戳逐帧检查，包括末帧、局部误差和帧间变化。候选即使降低全片平均误差，只要新增超过容差的局部坏帧或闪变，仍不采纳。

流程完成只说明已生成、校验和保存工程，不保证复刻质量。工程保留可编辑几何、文字、蒙版、关键帧和独立音轨；不会用原片作为视频图层来代替重建。

本次七次从零实验的冻结代码、模型输入、普通回答、逐帧证据、工程和成片保存在 `output/playwright/optional-vision/`。A 组验证无解析配置的完整流程；B/C 各三次比较中位数和稳定性，不能据一次最好结果改变默认路线。

本片实测 B/C 最终全片差异中位数分别为 0.2141/0.1758，但 C 三次视频首轮均需图片参数补正，且仍有明显画面偏差，未满足更改默认路线的条件。两次用量采集不完整的预跑单独保留，不参与正式七次比较。详细限制、额外调用和成片见实验目录的 REPORT.md。
